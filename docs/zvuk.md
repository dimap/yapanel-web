# Сбер Звук в панели

Панель умеет играть не только Яндекс Музыку. По умолчанию всё как раньше — Яндекс; на вкладке
**«Плеер»** есть переключатель **Яндекс Музыка / Сбер Звук**, и вернуться можно тем же переключателем.

Звук работает через штатный плеер станции: панель скачивает трек и отдаёт колонке ссылку
`http://<компьютер>:<порт>/zvuk/stream/...` командой `audio_play` по локальному Glagol. Поэтому
остаются штатными громкость, пауза, Range/продолжение с позиции и Алиса — она не глохнет.

## Что нужно

- Компьютер с панелью включён и находится в той же сети, что колонка: файл забирает **колонка**.
- Токен веб-сессии zvuk.com: он уже лежит в браузере после входа на сайт — панель берёт его со
  страницы `zvuk.com/api/tiny/profile` (вставляется весь JSON или одна строка `token`).
- Свободный порт на компьютере, по умолчанию **8767** (меняется переменной `ZVUK_SRC_PORT`).
  На Windows при первом запуске разрешите Python в брандмауэре для частной сети.
- Docker: используется `network_mode: host`, поэтому порт 8767 уже доступен в локальной сети.
  Если панель в другой сети/NAT, станция до неё не достучится.

Токен хранится только на компьютере панели — в `.zvuk_auth.json` рядом с `server.py` (или в
`--data-dir`), права 600. На колонку ничего не ставится, прошивка не меняется.

## Как включить

1. Откройте **«Плеер»** и переключите провайдера на **«Сбер Звук»** (если токена ещё нет, панель
   сама перейдёт на «Плеер»).
2. Войдите на [zvuk.com](https://zvuk.com) в браузере и откройте
   [zvuk.com/api/tiny/profile](https://zvuk.com/api/tiny/profile) — откроется текст JSON.
   Нажмите Ctrl+A, Ctrl+C и вставьте **всё** в поле в панели; панель сама найдёт поле `token`
   (можно вставить и одну строку токена). Если вместо текста открылся сайт — вы ещё не вошли.
3. Нажмите **«Сохранить»** — панель проверит токен запросом «Моего потока».
4. Нажмите **«Запустить поток»** или найдите трек поиском и нажмите **▶**.
5. Текущий трек, обложка, прогресс и кнопки — в обычном плеере панели (и на «Обзоре»).

### Раскладка «Плеера» у Звука

- Обычный макет (без бокового меню) — как у Яндекса: слева текст песни, справа блоки Звука; внутри
  блока настроение стоит над списком треков.
- Макет с боковым меню — блоки под плеером: **слева список треков, справа настроение**; исполнитель
  ниже, на всю ширину.
- Вкладки списка: **Очередь / Альбом / Похожие / Избранное / Поиск**. Выбор трека в «Альбоме»,
  «Похожих» и «Избранном» ставит очередь из этой вкладки. Строка включается кликом в любом месте
  (кнопки ▶ нет; «+» по-прежнему добавляет в очередь, «✕» убирает).
- Длинный список рисуется окном из 10 строк вокруг текущего трека; внизу — «Открыть плейлист
  полностью (N)», а в раскрытом виде — «Свернуть плейлист».
- Настроение: точка задаёт энергию (вверх) и веселье (вправо). **Популярность** — три положения,
  как в официальном клиенте: «Низкая» → `popular: 0`, «Средняя» → `popular` не передаётся (`NULL`),
  «Высокая» → `popular: 1`. Ниже — **жанр** и **язык**: «Любой» (`vocal: 1`, без языка), «Русское» (`language: "russian"`, `vocal: 1`),
  «Зарубежное» (`"foreign"`, `vocal: 1`), «Без слов» (`vocal: 0`, без языка). Именно так это делает
  Swift-клиент Звука; `vocal: 0` проверен живым API — возвращает инструментал/саундтреки.
  «Все жанры» не передаётся.
- **Жанры** — ровно те, что в официальном клиенте Звука: `pop`, `rock`, `hip_hop`, `electronic`,
  `classical`, `metal`, `indie`, `easy_listening_ambient`, `folk_world_country`, `soundtrack`,
  `instrumental_acoustic`. Можно выбрать несколько: компактная кнопка «Все жанры» / «Поп +2»
  открывает меню с галочками. Уходят массивом `genre: [{name, type: "LVL1"}, …]`, как у
  Swift-клиента. API принимает и другие строки (`jazz`, `latin`, `chanson`, `blues` в проверке
  работали), но неизвестные молча подменяет обычной волной — поэтому в меню только официальные.
- Громкость — штатная громкость колонки: панель показывает её из состояния станции, при обновлении
  страницы 50% больше не подставляются.
- Фон плеера окрашивается в цвет обложки и у Звука: обложка для canvas идёт через прокси панели
  (`/api/zvuk/cover`), потому что у CDN Звука нет CORS.
- **Избранное** — лайкнутые треки коллекции (`userTracks` + `getTracks`), четвёртая вкладка между
  «Похожими» и «Поиском». ♥ в плеере пишет в ту же коллекцию.
- ♥ и дизлайк: лайк — коллекция; дизлайк (🚫) — скрытие трека (`hidden_collection.addItem`), после
  него включается следующий.

### Очередь и кеш

- «Поток» идёт бесконечно: когда очередь из 10 треков заканчивается, панель сама берёт новую волну
  Звука и начинает её с первого трека. Следующий трек включается за ~0,35 с до конца текущего,
  поэтому паузы на стыке нет. Очередь из поиска/альбома остаётся конечной — новый поток по кнопке.
- В кеше `.zvuk-cache` лежат только файлы текущей очереди. При смене очереди, удалении трека или
  очистке очереди лишние файлы сразу удаляются; при запуске панели кеш чистится полностью.
- Если компьютер/панель выключились, очередь из памяти теряется; на колонке ничего не остаётся.

Текст песни у Звука берётся из LRCLIB по названию и исполнителю (у Звука своего текста в API нет);
если панель вошла и в Яндекс, сначала спрашиваем Яндекс. Работает и без входа в Яндекс.

Вернуться на Яндекс: переключатель **«Яндекс Музыка»**. Панель остановит Звук и снова покажет
яндекс-плеер; вход в Яндекс не затрагивается.

## Ограничения

- API «Звука» неофициальный, как и в [zvuk-yandex-station-player](https://github.com/derangedabbot/zvuk-yandex-station-player)
  (MIT; оттуда же GraphQL-запросы). Он может измениться, тогда поиск/поток перестанут работать.
- Компьютер — источник звука: выключили панель/компьютер — музыка остановится. Очередь хранится в
  памяти панели и после перезапуска теряется; кеш `.zvuk-cache` при старте очищается.
- Поиск возвращает треки, альбомы и исполнителей; в списке показываются треки, а альбом/исполнитель
  текущего трека доступны переключателем под плеером.
- «Уступить голосу Алисы» сделано только как возврат: если через ~3 с после старта на станции играет
  уже не наш трек (голосовой запрос перехватил управление), панель сохраняет провайдера «Яндекс»,
  переключает вкладку и плеер и показывает уведомление. Транспорт Звука голосом («дальше/пауза»)
  не перехватывается: Алиса не отдаёт панели текст команды, а `audio_play` — обычное медиа.
  Включение и переключение провайдера голосом есть через помощника: «Алиса, включи сберзвук» —
  помощник оставляет заявку, панель переключает на Звук и запускает «Мой поток»; «включи яндекс
  музыку» — обратно на Яндекс. Нужен установленный и запущенный помощник (см. voice-assistant.md).
- Дизлайк у Звука — это скрытие трека (`hidden_collection.addItem`), отдельного «не нравится» в API
  нет; скрытые треки можно вернуть (`removeItemFromHidden`), но отдельного списка скрытого в панели нет.
- Избранное выведено четвёртой вкладкой; плейлисты Звука пока не выведены — следующий шаг
  (`userPlaylists`/`getPlaylistTracks` есть).
- «Удалить всё с колонки» не трогает токен и выбранного провайдера — они живут на компьютере, а не
  на колонке. Токен можно удалить вручную: `.zvuk_auth.json`.

## yapanel 0.3.3 — свои слова активации на Станции Макс

Главное изменение: вкладка **«Активация»** теперь полностью управляет словами активации из yapanel. Отдельный maxpkg-пакет, YAM-пакет `tangenx/wakeword`, веб-панель на `0.0.0.0:8780` и отдельные autostart-блоки со станции удалены.

### Что нового

- **Обучение слову на станции**: фон, 6–15 дублей и обычная речь записываются с микрофонов колонки; модель и записи хранятся в `/data/wakeword`.
- **Активация Алисы через Frida**: агент внутри `com.yandex.io.sdk` вызывает `ru.yandex.io.sdk.jni.YandexIOSDKImpl.startConversation()`. SDK остаётся владельцем микрофона, второй `AudioRecord` не создаётся.
- **Управление из панели**: старт/стоп демона, статус, автозапуск, Frida-супервизор и прокси API — всё во вкладке «Активация».
- **Только loopback**: API демона слушает `127.0.0.1:8780`; отдельная панель на 8780 из LAN больше не доступна.
- **Boot hook** генерируется панелью: после перезагрузки поднимает и демон, и Frida-супервизор. `maxctl` и `/data/yam` в нём не используются.
- **Прогресс обучения**: отдельная карточка со стадиями `загрузка → обработка записей → обучение → проверка`, проценты и сообщение о завершении.
- **Пин бинарника**: sha256 `643c279b3327f1a110a8c65bc9e48bc70d305b4bee1efba1e491d9f94f61849f`; при несовпадении панель отказывается запускать демон.

### Установка и обновление

1. Скачайте `yapanel-web-0.3.3-windows-x64.zip` (или `arm64` для ARM-ноутбуков).
2. Распакуйте архив и запустите `install_to_max.bat`.
3. Введите IP-адрес станции.

Для уже установленной панели: обновите файлы панели, нажмите «Установить/починить файлы» во вкладке «Активация» и включите «Запускать при загрузке».

### Проверено на живой станции

- Два ребута: демон, Frida-супервизор и агент поднимаются автоматически.
- «Алёша, сколько времени?» → `startConversation` → ответ Алисы.
- Штатная Алиса продолжает работать.
- `maxctl ps` — без wakeword; `yam-run service list` — пусто.

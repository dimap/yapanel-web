# Локальный STT: необязательный Docker-контейнер

Устанавливается **только по желанию пользователя**. Панель не устанавливает
зависимости, не скачивает модель и не запускает распознавание автоматически.
Рекомендуемый способ установки — Docker, отдельным контейнером рядом с панелью.
На самой колонке Whisper не устанавливается.

Этот вариант требует работающего компьютера, панели и контейнера STT.
Если компьютер выключен или STT-контейнер остановлен, локальное распознавание
недоступно. Для работы без этого компьютера используйте облачный STT либо Алису.

## Установка по выбору пользователя

Из корня проекта:

```sh
docker compose -f docker-compose.yml -f docker-compose.stt.yml --profile stt up -d
```

Команда запускает панель и необязательный сервис распознавания. Первый запуск
скачивает зависимости и мультиязычную модель `base`; модель и ключ хранятся
в Docker-томе `stt-data`. Обычный запуск панели без файла `docker-compose.stt.yml`
и профиля `stt` ничего из этого не устанавливает.

Если панель уже запущена напрямую в Linux, запустите только STT:

```sh
docker compose -f docker-compose.yml -f docker-compose.stt.yml --profile stt up -d --no-deps stt
```

Ключ для настроек колонки:

```sh
docker compose -f docker-compose.yml -f docker-compose.stt.yml --profile stt exec -T stt cat /data/stt.key
```

В панели выберите:

- Источник речи: микрофоны колонки; подключите захват отдельной кнопкой.
- Распознавание: свой STT.
- Адрес: `http://IP_КОМПЬЮТЕРА:18445/v1`.
- Модель: `base`.
- Ключ: из команды выше.
- Язык: `ru`.

STT работает с любой текстовой моделью, в том числе Hermes и CommandCode,
и использует выбранный в панели синтезатор. Звук обрабатывается в памяти,
не сохраняется и не отправляется в облачный STT.

`base` — небольшой распознаватель, который может ошибаться, особенно в именах
и коротких командах. Для выхода всегда есть кнопка выключения режима в панели.
Если нужна другая модель Whisper, измените `command` сервиса `stt`, например
`["--model", "small"]`, и укажите то же имя в настройках ассистента. Более крупная
модель требует больше памяти и времени; она загружается только после выбранного
пользователем запуска контейнера.

Остановить только STT:

```sh
docker compose -f docker-compose.yml -f docker-compose.stt.yml --profile stt stop stt
```

Пустое распознавание не озвучивается. При реальной ошибке сервиса ассистент
сообщает об ошибке один раз и возвращает управление Алисе.

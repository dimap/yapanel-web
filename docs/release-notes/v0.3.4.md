## yapanel 0.3.4 — самодостаточный установщик для слов активации

Исправление после 0.3.3: установщик теперь приносит **все файлы**, нужные вкладке «Активация», и автоматически раскладывает их на станции.

### Что добавлено в установщик

- `frida-inject` 16.7.19 (android-arm64) — без него не работает активация Алисы через `startConversation()`.
- `negatives.bin` — набор негативов для обучения и переобучения слов.
- `audiocapture.jar` — fallback-захват микрофона через `AudioRecord`.
- `device/wakeword/install.sh` — после распаковки архива копирует бинарник, `negatives.bin`, `audiocapture.jar`, Frida-скрипты и `frida-inject` в `/data/wakeword` и `/data/local/tmp`.
- Кнопка **«Установить/починить файлы»** теперь докачивает все недостающие файлы, а не только бинарник. В статусе появился `files_ok`.

### Зависимости

- **maxctl и YAM для слов активации не нужны.** Демон запускается напрямую из `/data/wakeword`, boot hook использует `/odm/bin/start-stop-daemon` или `nohup`.
- Нужны только **root/su** и **Python 3** на станции — как и для самой панели.
- Обученная модель и записи (`/data/wakeword/words`) в установщик не входят: они создаются пользователем на станции.

### Установка

1. Скачайте `yapanel-web-0.3.4-windows-x64.zip` (или `arm64` для ARM-ноутбуков).
2. Распакуйте архив и запустите `install_to_max.bat`.
3. Введите IP-адрес станции.

Для уже установленной панели: обновите файлы и нажмите «Установить/починить файлы» во вкладке «Активация».

### Проверено

- Установщик содержит бинарник демона, negatives, jar, Frida-скрипты и `frida-inject`.
- После ребута демон и Frida-супервизор поднимаются автоматически.
- «Алёша, сколько времени?» → `startConversation` → ответ Алисы.
- `maxctl ps` — без wakeword; `yam-run service list` — пусто.

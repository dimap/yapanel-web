======================================================================
  YapAnel Hi-Fi & Party Mode v0.3.6 для Яндекс Станции Макс
======================================================================

БЫСТРЫЙ СТАРТ ДЛЯ WINDOWS:
1. Запустите файл install_to_max.bat (двойным кликом).
2. При запросе введите IP-адрес вашей Станции Макс (например 192.168.1.100).
3. Скрипт автоматически:
   - Проверит подключение по Wi-Fi через встроенный ADB
   - Проверит наличие Root-доступа (su)
   - Проверит и установит все библиотеки на колонке (tinytuya, requests, cryptography)
   - Зальет все файлы YapAnel на колонку (/data/yapanel)
   - Настроит автозапуск при включении колонки
   - Проверит запуск, восстановит аппаратный Hi-Fi DSP усилителей Silergy
   - Автоматически откроет панель управления в браузере (http://IP_КОЛОНКИ:8765/)
   - В случае успеха окно скрипта закроется само через 3 секунды.
   - В случае ошибки скрипт подробно напишет, чего не хватает.

ТРЕБОВАНИЯ:
- Яндекс Станция Макс (yandexstation_2) с root-доступом по ADB
- Компьютер и колонка должны быть подключены к одной локальной сети (Wi-Fi)


======================================================================
  ИНСТРУКЦИЯ: НАСТРОЙКА СВЕТОМУЗЫКИ (УМНЫЕ ЛАМПЫ TUYA / SMART LIFE)
======================================================================

НУЖЕН ЛИ АККАУНТ?
- Во время воспроизведения музыки: НЕТ. Колонка общается с лампочками
  на 100% локально по Wi-Fi через прямой TCP-сокет. Даже если отключить
  роутер от интернета, светомузыка продолжает работать без задержек.
- Для первоначальной настройки: ДА (один раз), чтобы извлечь уникальный
  локальный ключ шифрования (Local Key) каждой лампы.

ШАГ 1. ПРИВЯЗКА ЛАМП К WI-FI:
- Установите приложение Smart Life или Tuya Smart на смартфон.
- Добавьте ваши умные лампочки или светодиодные ленты к домашнему Wi-Fi (2.4 ГГц).

ШАГ 2. ПОЛУЧЕНИЕ LOCAL KEY (ОДИН РАЗ):
1. Зарегистрируйтесь на бесплатном портале разработчиков:
   https://iot.tuya.com
2. Перейдите в раздел Cloud -> Development -> Create Cloud Project.
3. В проекте перейдите на вкладку "Devices" -> "Link Tuya App Account"
   и отсканируйте QR-код через приложение Smart Life / Tuya на телефоне.
4. Откройте командную строку (cmd или PowerShell) на компьютере и выполните:
   pip install tinytuya
   python -m tinytuya wizard
5. Введите API Key и Secret из проекта iot.tuya.com. Утилита автоматически
   просканирует вашу сеть и сгенерирует файл "devices.json" со всеми
   IP-адресами, Device ID и 16-значными Local Key ваших ламп.

ШАГ 3. ПРИВЯЗКА ЛАМП ПРЯМО В ВЕБ-ПАНЕЛИ (САМЫЙ УДОБНЫЙ СПОСОБ):
Вам больше не нужно вручную создавать файлы или вводить команды ADB!
1. Откройте веб-панель в браузере (http://IP_КОЛОНКИ:8765/) и перейдите на вкладку «Светомузыка».
2. В карточке «Лампы в комнате» нажмите:
   - «🔍 Поиск в Wi-Fi» — Станция Макс сама прослушает сеть и найдет лампы Tuya (UDP 6666/6667).
     Нажмите «➕ Привязать» напротив найденной лампы: IP и ID подставятся автоматически!
   - Или нажмите «➕ Добавить лампу» для ручного ввода параметров.
   - Или нажмите «Импорт JSON» и просто вставьте содержимое сгенерированного файла devices.json.
3. Введите полученный 16-значный Local Key, задайте роль:
   - «🥁 Люстра — Бас / Kick (50–120 Гц)»
   - «🔔 Бра — Снэр / Snare (1 кГц)»
   - «✨ Фон — Мягкий эмбиент»
   и укажите панораму (слева / центр / справа).
4. Нажмите «Сохранить лампу».
5. Нажмите кнопку «💡 Тест» рядом с добавленной лампой — она мигнет 3 раза зеленым светом!

(АЛЬТЕРНАТИВНО) РУЧНАЯ ЗАЛИВКА bulbs.json ЧЕРЕЗ ADB:
Для продвинутых пользователей в папке сохранен шаблон "bulbs.example.json".
Вы можете отредактировать его и отправить на колонку командой:
  adb push bulbs.json /data/yapanel/bulbs.json

Готово! Включите Party Mode в веб-панели и наслаждайтесь мгновенной
светомузыкой и пространственным Ambilight без облаков и задержек!

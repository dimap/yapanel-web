## yapanel 0.3.7 — установка с root без su

Главное: установщик для Windows теперь понимает не только `su`, но и прямой root через ADB, а также варианты `su 0` и `sudo`. Это нужно для прошивок, где root есть, но классического `su -c` нет.

### Что нового

- **Проверка прямого root.** Установщик сначала смотрит `adb shell id`: если там `uid=0(root)`, все шаги выполняются напрямую, без `su`.
- **Варианты su.** Если ADB shell не root, проверяются `su -c id`, `su 0 id` / `su 0 sh -c id`, `sudo id`. Найденный режим используется для всех команд установки.
- **Понятная ошибка.** Если root нет ни одним способом, установщик показывает вывод `id`/`su`/`su 0`/`sudo` и подсказывает: включить root ADB, установить `su` или поставить панель вручную из root-сессии dropbear.
- **Исправлен `/api/say` на Максе.** Добавлен `urllib.parse` — резервный TTS больше не падает с `NameError: name 'urllib' is not defined`.
- **Включает всё из 0.3.6:** 10-полосная настройка АЧХ, две линии графика, остановка демона ассистента, понятные названия DSP-фильтров.
- **Тесты:** 825 passed.

### Если root только в dropbear

Прямой root через ADB и root в dropbear — разные каналы. Если `adb shell id` возвращает `uid=2000(shell)`, а `su` нет, установщик с Windows не сможет выполнить команды. Нужен root ADB, рабочий `su` или ручная установка из dropbear root-сессии.

### Установка

1. Скачайте `yapanel-web-0.3.7-windows-x64.zip` (или `arm64`).
2. Распакуйте и запустите `install_to_max.bat`.
3. Введите IP станции.

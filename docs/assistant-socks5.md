# SOCKS5 / SOCKS5H в ассистенте Станции Макс

Ассистент поддерживает SOCKS5 без авторизации и с авторизацией по RFC 1929.
Внешние Python-пакеты не требуются.

## Настройка

- socks5://proxy.example:1080 - DNS-имя назначения разрешается локально.
- socks5h://proxy.example:1080 - DNS-имя назначения передаётся SOCKS5-серверу.
- socks5h://user:password@proxy.example:1080 - авторизация логином и паролем.
- socks5h://user:p%40ss%3Aword@proxy.example:1080 - URL-кодирование спецсимволов.

При указанных учётных данных транспорт предлагает только метод авторизации RFC 1929,
без отката на анонимный SOCKS5. Запросы списка моделей, диалоги и HTTP API
озвучивания используют один и тот же urllib opener.

Проверка TLS-сертификатов HTTPS-сервера не отключается; стандартный Python ssl
использует SSL_CERT_FILE, если он задан.

## Установка

При установке или обновлении Python-ассистента через Yapanel вместе с
assistant_max.py устанавливается assistant_socks.py. Для SOCKS5 не нужен
внешний Python-пакет. Глобальный socket.socket не изменяется.

## Безопасность

- Не публикуйте config.json, URL прокси с авторизацией и API-ключи.
- Веб-панель показывает пароль прокси замаскированным (`socks5h://user:•••@host:1080`). При смене хоста или логина пароль нужно ввести заново.
- Сообщения ошибок SOCKS5 не содержат логин или пароль.
- На устройстве config.json должен иметь права 0600.
- Веб-панель с сохранёнными паролями желательно открывать по HTTPS.

## Релизная сборка

В embedded tar установщика `install_to_max.ps1` должен попасть `assistant_socks.py`. Иначе свежая установка через Windows получит `assistant_max.py` без SOCKS5-транспорта. При релизе пересоберите установщик и проверьте наличие файла.

## Тестирование

Запустите: python -m unittest discover -s tests -p 'test_assistant_socks.py' -v
Тесты используют локальные HTTP/SOCKS5-серверы и не требуют реальных секретов.
Для HTTPS-теста необходим openssl.

На реальной станции Макс (Android 9) проверены список моделей Gemini,
диалоги с SOCKS5H и логином/паролем, а также отказ подключения без них.

# Голосовые режимы ассистента

## Выбор обработки

- **Текстовая модель:** вопрос преобразуется в текст выбранным способом,
  отправляется в `/chat/completions`, ответ читает выбранный синтезатор.
- **Realtime:** ответ приходит собственным аудиопотоком модели. Он не передаётся
  в выбранный TTS. Для служебных сообщений используется настройка озвучки.
- **Источник «Алиса»:** сохраняет прежний способ — текст вопроса из журнала.
- **Источник «микрофоны»:** в режиме ассистента звук поступает напрямую в STT
  или Realtime. После выхода управление микрофонами возвращается Алисе.

Включение голосом по-прежнему начинает Алиса: «Алиса, переключись на GPT».
Прямой микрофонный разговор работает в режиме ассистента. Одноразовые команды
«Алиса, спроси GPT…» вне этого режима продолжают использовать распознавание Алисы.

Настройка STT провайдера использует адрес и ключ выбранной текстовой модели.
Для OpenAI и Groq предусмотрены стандартные имена STT-моделей; для других
провайдеров нужно указать поддерживаемую ими модель. Если у провайдера нет STT,
выберите отдельный OpenAI-совместимый сервер распознавания или источник «Алиса».
Свой STT имеет независимые адрес, ключ, модель, язык и прокси.

Для озвучки «Своим синтезатором» есть пресет **FishAudio**: адрес
`https://api.fish.audio/compat/v1`, модель `fish-audio/s2.1-pro-free`, голос — id из
Fish Voice Library (пустой — голос по умолчанию), нужен только API-ключ Fish.

Стандартные провайдеры текстовой модели: OpenAI, OpenRouter, Groq, Google Gemini,
OrcaRouter, Command Code, Ollama, LM Studio. OrcaRouter — OpenAI-совместимый шлюз
(`https://api.orcarouter.ai/v1`), имена моделей берутся из его `/models`.

## Локальное распознавание — только по выбору пользователя

Панель не устанавливает локальный STT автоматически и не скачивает модель
вместе с обычной установкой ассистента. Если пользователь хочет локальное
распознавание, рекомендуемый способ — [необязательный Docker-профиль](../tools/local-stt/README.md).
Для этого варианта нужны включённый компьютер, работающая панель и контейнер
Whisper. Панель может быть запущена напрямую в Linux. Когда локальный сервис остановлен, он не может распознавать речь.
Облачные STT и Realtime не требуют запущенного сервера панели для обработки
каждого вопроса: их вызывает программа на самой колонке.

## Совместная работа с Алисой

Микрофонный захват включается отдельной кнопкой и пока проверен на Лайт 2.
Подключение и отключение ненадолго перезапускает службы Алисы. Исходная
конфигурация остаётся в прошивке; подмена действует через bind mount.
Если захват не подтверждён, отдельный watchdog выполняет откат.

В микрофонном режиме ассистента Алиса временно получает тишину, а внешний
помощник — копию звука до заглушения. При выключении режима, выходе программы
или прекращении обновления lease оригинальный звук возвращается Алисе.
Во время ответа вход не передаётся обратно в распознавание: это защищает
от повторной обработки собственного голоса. Остановить ответ или выключить
режим можно кнопками панели. В этом режиме прерывание голосом во время ответа
пока не реализовано.

После ответа включённая «Беседа без Алисы» продолжает прямое прослушивание.
Без неё следующий вопрос требует новой активации. Точность голосового выхода
«верни Алису» зависит от STT; кнопка панели от него не зависит.

Пустой результат STT — отсутствие распознанной речи, поэтому он не озвучивается
и не добавляется в историю как ошибка. После него детектор учитывает уровень
ложного срабатывания и делает короткую паузу. Настоящая ошибка сети или API
озвучивается один раз, затем режим выключается, возвращая управление Алисе.

## Проверено на устройстве

- Копирование микрофонного потока параллельно Алисе.
- Hermes → выбранный NecoArcRu без смены модели и синтезатора.
- Микрофоны → локальный Whisper `base` → Hermes → NecoArcRu:
  распознано «Сколько будет два, плюс два?», получен и озвучен ответ «четыре».
  Пользователь подтвердил, что на слух одновременной речи Алисы не было.
- Обнаружен ошибочный голосовой цикл на пустых результатах STT; после
  исправления добавлен регрессионный тест отсутствия озвучки и записи ошибки.
- Проверен возврат исходного аудиотракта после отключения захвата.

Whisper `base` ошибся на короткой команде «верни Алису», распознав «вернее Одессу».
Такой текст не подменяется командой автоматически: случайное распознавание
обычного вопроса не должно выключать режим. Для надёжного выхода есть панель.
Локальный STT после эксперимента остановлен и удалён; настройки Алисы восстановлены.

Realtime WebSocket, отправка PCM, разбор входящих аудиоданных и обработка ошибок
проверяются тестами с локальным сервером. Полная проверка с настоящим внешним
Realtime-провайдером пока требует API-доступа; подписка на чат сама по себе
не является сохранённым API-ключом.

Дополнительные проверки Realtime: отмена закрывает WebSocket; возврат к Алисе
останавливает уже накопленный звук вместо его дочитывания. Если проигрыватель
не отвечает на мягкую остановку, процесс завершается принудительно через
ограниченное время. Ошибка авторизации озвучивается один раз выбранным
синтезатором, после чего микрофоны возвращаются Алисе. Поздние события
отменённого запроса не меняют состояние следующего разговора.

## Зависимости настроек в панели

Для OpenAI доступен явный выбор текстового API или Realtime. При переключении
подставляется совместимая модель; название можно изменить в поле модели.
Разговорные Realtime-модели также распознаются автоматически. Обычная текстовая
совместимость API не считается подтверждением поддержки Realtime. Список моделей
OpenAI для разговора исключает отдельные STT, TTS, embeddings и другие
специализированные модели.

В Realtime скрыта настройка обычной озвучки и STT. Голосовой ввод вынесен отдельно:
модель может получить либо распознанный Алисой текст, либо прямой звук микрофонов.
При вводе через Алису скрыты STT и чувствительность микрофонов; на неподдерживаемых
моделях колонки прямой захват не предлагается. Уже подключённый захват можно
отключить, даже если источником снова выбрана Алиса.

STT провайдера предлагается для подтверждённых OpenAI и Groq. Для остальных
доступна настройка своего STT. При озвучке Алисой скрыты адрес, ключ, модель,
голос и скорость стороннего синтезатора. Цвет кольца скрыт при выключенной
подсветке. При прямом Realtime-вводе скрыты пользовательские текстовые фразы
выхода: возвращение к Алисе обрабатывает голосовая модель.

Сохранение не перезаписывает неиспользуемые разделы: при Realtime сохраняются
прежние параметры обычной озвучки и STT, при вводе через Алису — параметры
прямого захвата. Они снова появляются при выборе соответствующего режима.

В блоке «Голосовой ввод» выберите микрофоны колонки, затем «Свой STT».
Появятся поля подключения и инструкция запуска локального Whisper.
Настройки применяются после сохранения.
Подключение микрофонов показывает ход операции и её результат прямо в блоке.
Старая версия сервера панели распознаётся отдельно: требуется перезапуск панели,
а не повторные нажатия на кнопку.

## Локальные команды (без модели)

В разделе «Локально» включаются ответы, которые считаются на самой колонке и не
обращаются к модели:

- «Время и дата» — «который час», «какое сегодня число», «какой день недели».
  Работает без сети и без настроек. Колонка живёт в UTC, поэтому панель при
  установке и сохранении копирует рядом с конфигом свой `localtime` (тот же приём,
  что у будильника); без этого файла время осталось бы UTC.
- «Погода» — сейчас и на завтра. Запрос делает колонка в MET Norway
  (api.met.no), ключ не нужен.
  Город определяется кнопкой «Определить» по IP панели (приблизительно, по сети
  компьютера с панелью) или вводится вручную — тогда панель один раз геокодирует
  название и сохраняет координаты. Если координаты не заданы, вопрос уходит модели
  как обычно.

Совпадение строгое: «который час в Лондоне» и длинные фразы локально не
перехватываются. Локальные ответы не тратят токены, не ждут API и в истории
помечаются как «локально».

## Музыка

Провайдер музыки переключается голосом через того же помощника (on-device, без
установки на колонку):

- «Алиса, включи сберзвук», «включи сбер звук», «переключи на сберзвук» —
  помощник оставляет заявку `music: {provider: "zvuk", play: true}`, панель
  переключает провайдера на Сбер Звук и запускает «Мой поток».
- «включи яндекс музыку», «переключи на яндекс», «верни яндекс» — обратно на
  Яндекс; панель запускает «Мою волну».

Панель забирает заявку из статуса помощника каждые ~1.5 с (и при открытой
вкладке «Помощник»), после чего подтверждает её командой `music_seen`. Если
помощник не установлен/не запущен или панель выключена, переключения не будет.
Транспорт Звука («дальше/пауза») голосом по-прежнему не управляется — только
выбор провайдера и запуск потока.

# bt-memes для панели

Нативный демон для Станции Макс: глушит аппаратные ключи усилителей Silergy
SY6045S на время фразы Алисы при включении/выключении Bluetooth и затем
проигрывает джингл.

- `bt-memes` — собранный aarch64-бинарник (static).
- `bt_memes_daemon.c` — исходник.
- `sounds/silent.mp3` — тишина для голосовых подсказок Quasar.

Пользовательские звуки (`ruko_blud.opus`, `penis_her.opus`) в публичный
репозиторий не входят. Их можно загрузить через панель: «Bluetooth» →
«Звуки Bluetooth» → «Загрузить». Панель кладёт файлы в `sounds/` рядом
с бинарником; демон подхватывает их и копирует в системные звуки Quasar.

Панель сама устанавливает бинарник в `/data/quasar/webpanel/bt-memes`,
запускает/останавливает демон и хранит резервную копию оригинальных
`bluetooth_turning_*` звуков.
